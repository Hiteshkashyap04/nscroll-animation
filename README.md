# Scroll-Driven Hero Section Animation

A scroll-driven hero section recreated using **Next.js, React, Tailwind CSS, JavaScript, and GSAP**.

The project focuses on creating a smooth, interactive hero animation inspired by modern automotive websites, where the main visual moves horizontally with the user's scroll position and supporting statistics appear progressively.

## 📌 Project Overview

This project was developed as part of a frontend development assignment.

The objective was to create a visually engaging hero section featuring:

- Letter-spaced hero typography
- Smooth initial page-load animation
- A car as the main visual element
- Scroll-driven horizontal movement
- Progressive statistics revealed during scrolling
- Colored visual effects and motion trails
- Smooth easing and interpolation
- Responsive behavior

GSAP and ScrollTrigger are used to synchronize the main visual animation with the user's scroll position.

## ✨ Features

### Hero Section

- Full-screen sticky hero section
- Large letter-spaced `WELCOME ITZFIZZ` headline
- Smooth fade-in and upward movement on initial page load
- Minimal visual layout
- No unnecessary navigation or footer elements

### Scroll-Driven Animation

- Car starts from the left side of the screen
- Car moves horizontally as the user scrolls
- Movement is synchronized with scroll progress using GSAP ScrollTrigger
- Smooth scrubbing creates a natural scrolling experience

### Animated Statistics

Four statistics are revealed progressively as the car moves:

- **58%** — Increase in pick up point use
- **23%** — Decreased in customer phone calls
- **27%** — Increase in pick up point use
- **40%** — Decreased in customer phone calls

Each statistic has its own colored visual treatment and appears at a different stage of the scroll animation.

### Visual Effects

- Soft colored background glows
- Multi-colored motion trails behind the car
- Translucent statistic cards
- Subtle blur effects
- Smooth transitions
- Minimal visual design

### Responsive Design

The layout adapts to:

- Desktop
- Tablet
- Mobile

Animation positioning and statistic sizing are adjusted for smaller screens.
